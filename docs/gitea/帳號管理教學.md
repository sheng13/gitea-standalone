# Gitea 帳號管理教學（admin 怎麼控制帳號）

> Gitea 本來就有完整的 admin 帳號管理功能（網頁後台 + 指令都行），不需要另外開發。
> 這份教你身為 admin 怎麼開/停用/刪除/改密碼/設權限。
> 管理員帳號：admin（密碼請改掉，預設 <CHANGE_ME>）。

## 方式一：網頁後台（最直覺，點點點）

1. 瀏覽器開 http://<PRIVATE_IP>:3000 → 用 admin 登入
2. 點右上角「頭像」→ 選單裡點「Site Administration」（站台管理）
3. 左側選單點「User Accounts」（或 Users）→ 看到所有帳號清單
4. 點任一個使用者進去，可以：
   - 設為管理員（Make admin）/ 取消
   - 啟用 / 停用（Disable / Enable）
   - 刪除（Delete）
   - 重設密碼
   - 改權限、限制最大倉庫數等

> 註：若網頁後台的 User 頁在你這個版本點不進去（少數 1.23 路徑調整），直接用下面的「方式二 指令」，保證可用。

## 方式二：指令（最穩，已實測可用）

所有指令都在 ~/gitea-standalone 目錄下執行，要帶 -c app.ini。

### 列出所有帳號
./gitea admin user list -c app.ini
（實測輸出範例：
 ID   Username Email              IsActive IsAdmin
 1    admin    admin@local.com    true     true
 2    teammate teammate@local.com true     false
）

### 開新帳號（最常用）
bash manage.sh adduser 帳號 密碼
例： bash manage.sh adduser li 密碼123
（等價指令： ./gitea admin user create --username li --password <CHANGE_ME> --email li@local.com -c app.ini）

### 改某個帳號的密碼
./gitea admin user change-password --username 帳號 --password <CHANGE_ME> -c app.ini
例： ./gitea admin user change-password --username teammate --password <CHANGE_ME> -c app.ini

### 停用 / 啟用某帳號
./gitea admin user change-password 沒有停用參數，停用請用網頁後台；
或用 SQL：
PGPASSWORD=<CHANGE_ME> psql -h 127.0.0.1 -U gitea -d gitea \
  -c "UPDATE \"user\" SET is_active=false WHERE lower_name='帳號';"

### 刪除帳號
./gitea admin user delete --username 帳號 -c app.ini
例： ./gitea admin user delete --username teammate -c app.ini

### 設某帳號為管理員
./gitea admin user change-password 不管權限；設管理員用：
PGPASSWORD=<CHANGE_ME> psql -h 127.0.0.1 -U gitea -d gitea \
  -c "UPDATE \"user\" SET is_admin=true WHERE lower_name='帳號';"

### 強制使用者下次登入改密碼
./gitea admin user must-change-password --username 帳號 -c app.ini

## 目前帳號狀態（實測）
- admin（你是管理員，IsAdmin=true）
- teammate（一般帳號）

## 小提醒
- 網頁後台能做的事情最全；指令法適合快速操作或寫腳本。
- 改完密碼後，記得告訴該同事新密碼。
- 停用帳號後他登不進去，但他的倉庫資料還在，之後啟用就能恢復。
